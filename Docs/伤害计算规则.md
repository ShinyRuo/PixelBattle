# 伤害计算规则

## 傀儡之体与内心的爱（2026-09-16）

蝎的每次普攻命中追加一层独立毒伤，每秒 `10 + 4×等级`，共五跳。伤害类型由蝎的攻击属性决定为忍术，伤害事件属性为风（原脚本 ATTACK_TYPE_PIERCE），吃忍术增伤 / 穿透与目标忍术抗性、七属性关系，不吃护甲。普通攻击本身仍为体术。周期毒伤不另掷暴击。

内心的爱将每层伤害乘 1.5，挂上时每层减甲 2 点，第五跳结算后移除该层减甲；毒伤自身不因减甲增伤，队友体术可受益。叠层没有人为上限，普通六槽溢出不驱散毒层；来源数值及羁绊采用命中快照，来源死亡或后来变化不追溯旧层。原版到期回甲时重查羁绊的做法未沿用，以避免永久减甲残留。

减攻速另为单份 ×0.7、每次刷新 5 秒。羁绊还使己生转生赠送公式最终倍率为 1.5，仍遵守双重取整、五秒献祭及本波属性重置。8 项专项与 1187 项默认测试通过；未深度配平。蝎控制 / 负面免疫、毒层数量专用标识仍待完善。

## 心转分身与临时阵营（2026-09-16）

- 主目标按施法者等级严格大于敌人等级时转为友方，否则眩晕；时长为 1/1/2/2/2/3/3/4/4/5 秒。主效果与施法者引导关联，死亡、眩晕、沉默、主效果被清除等会中断。
- 第十班追加目标只眩晕，时长两倍，独立计时；没有采用旧说明里未获脚本支持的“主目标 +1 秒”。
- 临时友方敌人保留普攻起手、间隔、弹道、暴击、穿透、两类伤害和七属性计算。双方怪物互相寻敌 / 移动 / 攻击；忍者不再将其视为目标。旧敌方弹道若来源当前已转化，不再伤害忍者。
- 转化单位不漏怪；死亡记敌方击杀，不计忍者阵亡。转化期间停用怪物主动技能，尚未实现主动技能改选敌方目标。
- 普通及当前仅增加生命的精英波暂用单位等级 1；BOSS 用 `2 + floor(波数 / 4)`。这是对当前波次模型的适配，不代表已完成原版所有怪物等级分配。
- 原版额外目标要求 A05I 标记；当前以已出生、存活敌人为候选。原版 1 秒施法起手、分级耗蓝及施法距离仍未接入，沿用 0.35 秒弹道。
- 13 项新测试、1179 项默认测试均通过；转化双方两类伤害 × 七属性 × 近战 / 弹道已覆盖。原版差异如上，不据此宣称技能全部还原。

2026-09-15，玩家明确并替代旧文档中混用「物理伤害」的说法。

## 两条独立的轴

| 轴 | 值 | 负责什么 |
|---|---|---|
| 伤害类型 `PBDamageKind` | 体术、忍术 | 护甲 / 忍术抗性，暴击与增伤分型 |
| 攻防属性 `PBElement` | 风、火、雷、土、水、物理、仙 | 七属性攻防克制倍率 |

- 所有忍者普攻默认体术；宇智波鼬的 `attack_ninjutsu` 被动将普攻转换成忍术。
- 忍者技能按**施法者攻击属性**分型：物理属性是体术，其他六种是忍术。包括通用大招、角色技能和阵亡技能。
- 技能自己的 `element` 用于克制，可与施法者攻击属性不同。例如火属性忍者使用物理属性技能，仍是「忍术伤害 + 物理属性克制」。
- 旧表沙铁界法、日晕舞的 `kind=体术` 配置已按玩家新规则撤销，不能再据原版文案里的「物理伤害」改回来。
- `TAIJUTSU` 保留旧枚举数值 0，`NINJUTSU` 保留 1；`PBElement.PHYSICAL` 没有改名或移动。

## 基础伤害

- 体术普攻：总攻击力。保留按角色主属性派生攻击力的机制，装备提供的攻击和属性参与计算，不统一强制敏捷。
- 忍术普攻：总智力 × 普攻系数；当前系数暂为 1。普攻转换与暴击不再隐含使用攻击力作为智力的替身。
- 敌人忍术攻击：`PBWave.intellect_each × ninjutsu_coefficient`，出生时复制给敌人；不拿体术攻击力充当智力。要配置忍术敌人，必须同时提供类型和智力基数。
- 技能：`base + growth × (技能等级 - 1) + 指定属性 × 系数 + 最大生命 × hp比例`。
- 默认体术技能取攻击力、忍术技能取智力。原版明确使用敏捷、力量或生命值的例外通过 `stat` / `hp` 显式配置；使用哪个属性不改变伤害类型。
- 现有技能等级仍取施法者等级；装备、训练、羁绊与尾兽的属性词条先合并，再生成本波技能伤害。单次技能伤害不再包含攻速。
- `power_mult` 历史字段名保留，但现为属性系数；羁绊 `power_scale` 同时放大固定基数、成长、属性系数和生命比例，避免只放大公式的一部分。

## 增伤与结算

| 键 | 作用范围 |
|---|---|
| `damage_bonus` | 普攻专用，两类普攻都可受益 |
| `damage_scale`（临时效果） | 现有普攻倍率，仍为普攻专用 |
| `all_damage_bonus` | 两类普攻、技能和有施加者来源的伤害效果 |
| `taijutsu_bonus` | 体术伤害 |
| `ninjutsu_bonus` | 忍术伤害 |

同名常驻词条相加；通用、对应类型与普攻专用加成分组相乘。宇智波一族的「伤害 +40%」已迁移为通用增伤。
其他历史上用普攻倍率近似的被动 / 攻击力增益继续按表标明的近似处理，并不代表所有原版被动已完整还原。

结算顺序：基础伤害 → 克制和适用增伤 → 对应类型暴击 → 对应防御与穿透 → 目标受伤倍率 → 护盾 → 生命。

- 体术：有效护甲 = 护甲 × (1 − 护甲穿透)，走既有护甲递减曲线。
- 忍术：有效抗性 = 忍术抗性 × (1 − 忍术穿透)，伤害乘 (1 − 有效抗性)，不读护甲。
- 抗性与穿透按成数，上下限按现有规则钳制。例如 40% 抗性、50% 穿透，剩 20% 抗性。
- 两类基础暴击均为 2 倍，分别读取对应暴击率和暴伤。零暴击率不消耗随机流。
- 敌我共用 `PBDefenceRules`；敌人的伤害类型、两类增伤 / 暴击和穿透由波次快照传到出生对象。忍者常驻、临时忍术抗性均有实际减伤入口。
- 敌人弹道保存出手时的类型、暴击和穿透；飞行中来源词条改变不能把忍术弹变成体术弹。

## 伤害效果

技能附加的即时、周期伤害继承该技能的伤害类型和七属性；被动附加效果按施加者攻击属性确定技能伤害类型。
保存施加时的来源槽位、通用 / 分型增伤与穿透，不持有施法者引用；施法者死亡不取消已生效的效果。
这些效果默认不暴击。每份持续效果先各自计算克制与防御，再合计交给敌人统一扣血。
没有施加者、也没有技能上下文的旧构造点继续按裸忍术效果处理，不能凭空猜属性或穿透。
反弹与闪避反打保留现有特殊规则，不重复放大已经结算过的伤害。

## 已迁移范围与数值边界

技能表已转录 27 项公式（含早蕨之舞的力量项、黏土蜘蛛当前合并爆炸的近似）。
这不表示多段次数、扇形、距离加成、百分比目标生命、持续时间和召唤物全部还原。

另有 3 项持续技能已接入原版每跳公式与时长，见下节。

另有 2 项多段技能已接入原版段数与单段公式，见「多段技能第一批」。

须佐能乎、森罗万象的基础技能原文没有直接伤害，已移除暂定伤害项，见「控制与防御技能修订」。

追牙之术已移除额外伤害，改由真实召唤物按原版攻击继承比例输出，见「追牙与召唤追击」。

此前标记的暂定属性系数已全部替换；金刚封锁改为无直接伤害的范围减速与沉默。机制与表现的待办仍见下文。
逐个还原这些技能时，应同时处理其原版多段 / 周期机制和公式，不能把一次伤害直接当成全程总伤害。

敌人普通波仍默认体术，未自动给具体怪物配置新的忍术能力。
尾兽大招保留「全队输出 × 倍率」的独立模型；本次忍者属性公式不将尾兽伪装成具有智力属性的忍者。

本次只做功能回归与截图，未运行深度配平。伤害量与推波位移留待已授权的数值回归。

- 当前仍是「命中时选定目标并挂持续效果」，没有实现可反复进入、离开的持续地面区域；五影齐聚、真数千手等技能变体另排，不在本批声称完成。

- 说明卡展示每段公式 / 段数 / 间隔，战场按真实每段落点与半径画短暂命中圈。

依据原版 §5 的 A01G / A01N。两项基础技能没有直接伤害，不能以暂定系数补一发爆发。

| 技能 | 基础效果 | 等级 1–10 的时长（秒） |
|---|---|---|
| 须佐能乎·自身 | 护甲增加 `10 × L`、忍术抗性增加 40 个百分点 | `2,2,3,3,3,4,4,4,4,6` |
| 须佐能乎·周围 | 300 码（半径 0.15）内眩晕，禁止移动和攻击 | `1,1,1.5,1.5,1.5,2,2,2,2,2.5` |
| 森罗万象 | 只缠绕选定的敌人，定身并禁止攻击 | `0.5 + 0.5 × L`，即 1–5.5 |

- 说明卡对无伤害控制显示「无直接伤害」，有周期伤害的技能仍标注体术 / 忍术类型。
- 完全体形态、天降陨石、明神门等羁绊变体不在本批范围，不能将基础技能修订记作变体完成。

## 追牙与召唤追击（2026-09-15）

依据原版 §5 的 A00W：束缚一个目标 5 秒，使其无法移动；召唤 5 只忍犬，
每只攻击力为本体 `(30 + 3 × L)%`，雷属性攻击，存在 5 秒。原文没有额外瞬间伤害。

- 移除旧的系数 2 伤害与技能弹道，施法落地时直接束缚并召唤。束缚只有定身，不禁止目标攻击。
- 每只忍犬的攻击继承从 1 级 33% 增长到 10 级 60%，而非固定 45%；单次攻击不乘攻速。
- `summon_power_at(level)` 统一计算基础与成长，普通施法、受击召唤及说明卡均传入等级。
- 〔永远的对手〕的 `summon_power_scale=1.7` 同时放大基础与成长，1 级 / 10 级分别继承 56.1% / 102%。
- 忍犬普攻走体术通道、吃护甲；雷仅表示攻击克制属性，继承自当前雷属性本体。没有添加额外的智力忍术攻击。
- 每只召唤物记住施法目标，在目标有效时追击并优先攻击，不为附近其他敌人开火；原目标死亡 / 失效后恢复普通索敌。
- 发出指令时扣蓝一次、落地时进入冷却。落地前目标已失效则空放，不改绑其他目标、不召出无目标追击队。
- 召唤物会挨打，施法者死亡不提前移除它们；到期自然散场不计己方阵亡，复用槽位清掉旧追击、瞄准和起手状态。
- 修复所有召唤物未继承本体 `leash` 的问题：原先预留位默认 0，可能把它们拴在出生点而无法接敌。
- **仍为近似**：生命沿用本体 30%，射程 / 攻速 / 移速 / 护甲沿用本体；原版技能文本未给出这些忍犬独立属性。出生位置沿用本体身边。
- **表现未完成**：目前使用通用白模召唤物，未接犬形素材、犬类动画。神威的吸附与持续伤害也不属于本批完成范围。
- 召唤槽位仍按开波预留数量共享；正常 27 秒冷却长于 5 秒寿命，冷却重置后的叠放仍受空闲槽位限制，未在本批扩展容量机制。

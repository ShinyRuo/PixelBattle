## 2. 交付格式和工具

- 完整提示词见 [素材规格_特效](素材规格_特效.md)「新增类型提示词模板」及 [AI出图_战场形象](AI出图_战场形象.md)「施法与召唤物」。
- 原图放 `aires/skills/<技能键>/`、`aires/buffs/<BUFF键>/`、`aires/summons/<召唤物键>/`；原始素材不进版本控制。交付时带上本清单资源键。
- 六帧成品命名 `<资源键>_00.png` 到 `_05.png`。循环段首尾相接；命中/出现/消失段单次播放。前后层分别用 `_back_00.png`、`_front_00.png`，同画布同锚点。
- 表内 `cast` 是独立起手特效；**角色动作**另命名 `cast_<技能键>_00.png`…`05.png`，二者不要混用。
- 模板编号：C 起手、F 飞行（沿用子弹模板）、H 命中、A 区域、L 连线、B 环身 BUFF、S 召唤物四态。
- 人物动作在 **战场形象** 工具直接处理整张序列图，输出 `skill1/skill2` 并生成形象表；在 **战场特效 → 技能表现** 选择已有动作绑定。战斗已固定六帧 / 0.6 秒，第 4 帧（0.3 秒）释放，独立于攻速；缺配置回退攻击动作。
- 表内 C 类起手特效在 **战场特效 → 起手光效** 页直接切整图，按资源键保存，再在技能表现页选择绑定。六帧默认 20 fps，仅 0–0.3 秒播放；释放/打断时撤下，不占 BUFF 槽。专属 PNG 仍待生成，临时演示金光未留作正式绑定。
- 子弹先在 **战场特效 → 子弹** 页生成，随后技能表现页选择已生成键并绑定。写回 `data/skills.tsv` 的 `shot=` 和生成资源，重新生成技能不丢绑定。支持 `fly=` 真实弹道，以及点地面且 `delay>0` 的纯表现载体；不改变落点、飞行速度或命中时刻。其他类型拒绝绑定。
- 当前可绑定真实弹道的技能：心转分身之术、影子模仿术、水遁·水龙弹术、幻术·霞、月读。影子模仿的飞行前段与持续连线仍是两项资源。
- 地面延迟技能的载体也可绑定，例如无限鲛、火龙炎弹、大豪火球；无限鲛只是把既有延迟载体换成鲨鱼，不生成新的伤害子弹。灰积烧等技能可保留默认载体，优先制作实际需要的区域与命中。
- 改回基础四态时保留专属施法段；不要直接覆盖整个形象资源。没有或无效的技能映射均回退攻击动作。
- 忍者持续/周期 BUFF 可在 **战场特效 → BUFF光效** 页导入前后层帧、预览与保存，见 [BUFF光效配置](BUFF光效配置.md)。敌方持续/周期BUFF也可绑定亮色状态光；瞬间 BUFF、移动/扩圈区域仍待接；召唤物四态/远程子弹已可在「召唤物表现」页绑定。

## 8. 验收与交付检查

1. 每段只有一种效果，无文字/水印/地板/人物烘焙；身体动作单独交付。
2. 所有帧同尺寸、同中心/脚底锚点；主体不越框；循环尾帧接回首帧；无需每帧重新自动裁边。
3. 发光黑底走加法；黑影/灰烟/骨头/木头走普通透明，不用黑底抠掉黑色主体。优先真实透明 PNG；不支持透明时实体用纯洋红底再处理。
4. 地面区域交付未压扁的俯视正圆，视角压缩由引擎做；身体光前后层同画布；连线只交可拉伸段与端点。
5. 光效不改变判定、攻击速度、伤害属性或范围；32 个 BUFF 不能等于屏幕叠 32 个不透明壳，亮度与显示优先级另在表现层控制。
6. 导入后检查实战暂停、倍速、死亡、取消、被挤出和换波清理；当前未接入的类别不宣称完成这些验证。

- 召唤技能：`shadow_clones`
- 形象资源：`data/actors/summon_shadow_clones.tres`

Create summon_shadow_clones as an exact visual match to the supplied existing Naruto battle-sprite references: same teenage blond spiky hair, blue forehead protector with metal plate, three whisker marks on each cheek, orange-and-black zip jacket and trousers, blue open-toe shinobi sandals, small thigh pouch, same cel-shaded high-resolution game illustration style and proportions. Deliver exactly TWENTY-FOUR sequential frames in a strict 6-column by 4-row grid of equal square cells, overall 3:2 landscape sheet. Row 1: idle breathing loop, six subtle frames. Row 2: running in place toward screen-right, six smooth frames with planted feet. Row 3: close-range ninja punch/kick attack, six frames, with the first frame already at the decisive strike pose so gameplay damage and motion align. Fixed orthographic side view, fixed camera, character faces screen-right except while falling. Same feet baseline, same body scale, and same center in all standing frames. No translational motion across cells.

Size constraint: standing figure should occupy about 72–76 percent of each square cell height with transparent headroom and foot room. The final in-game visible height must be approximately 150 pixels after cutting and binding; keep identical scale across idle/run/attack. Every pose must remain fully inside its cell, including limbs.

Genuinely transparent RGBA background in every cell. No black backdrop, no magenta, no checkerboard. No extra clones inside a cell, no scenery, no UI, no labels, no text, no watermark, no grid lines or cell borders, no weapons, no alternate costume, no glowing transformation aura. Preserve the supplied character identity and outfit exactly. Deliver one flat sprite sheet image only.

## 切图与配置

`build/codex-setup/build_shadow_clone_art.gd` 清理低透明残像后调用现有 `PBSheetCutter` 切分 24 帧，再由 `PBActorForge` 按 idle 的统一缩放和脚底基准归一化四态。生成图最后一帧的两簇消散烟被切图器识别为两个连通块，加工脚本将它们合并回第六个死亡帧，最终仍严格保持四态各六帧。

# 召唤物表现配置

## 入口与流程

1. **战场形象插件**：填写独立角色键（例如 `summon_puppet_crow`）。每段可直接导入 AI 生成的一张序列帧图，用现有切图、挑帧、锚点、缩放工具加工 `idle / run / attack / dead`，各六帧。导出四段后点击「生成形象表」。也可复用已经做好的忍者四态，无需复制素材。
2. **战场特效 → 子弹**：为远程召唤物制作独立命名的飞行段，例如 `summon_puppet_crow_bullet`；同样可直接选 AI 序列图切分，点击生成资源。当前不要求新增技能受击素材，可关闭命中段。近战召唤物跳过这一步。
3. **战场特效 → 召唤物表现**：选择召唤技能，点击「刷新资源 / 读取已保存绑定」，分别选择四态形象和远程普攻子弹，切换 `idle / run / attack / dead` 检查预览，点击「保存召唤物绑定」。未保存的选择只影响本页预览。
4. 重新运行游戏，在 debug 窗口直接出战对应忍者，施放技能检查大小、脚底锚点与子弹出手位置。

形象的缩放、脚底、朝向、出手点均沿用形象资源；子弹的缩放、过滤、透明/加法混合沿用子弹资源。插件中形象与飞行段以两倍大小预览，战斗读取原始缩放；本页子弹预览展示飞行循环，不模拟弹道或射程。

## 支持对象

| 技能 | 建议形象键 | 子弹说明 |
|---|---|---|
| 影分身 `shadow_clones` | `summon_shadow_clones`，也可选本体形象 | 仅实际远程攻击时使用，可选择本体已有子弹 |
| 白绝复制体 `white_copy` | `summon_white_copy` | 仅实际远程攻击时使用 |
| 傀儡术·乌鸦 `puppet_crow` | `summon_puppet_crow` | 可绑定毒针等飞行段 |
| 通灵术·吸血虫 `vampire_bugs` | `summon_vampire_bugs` | 可绑定虫弹等飞行段 |
| 追牙之术 `pursuing_fangs` | `summon_pursuing_fangs` | 近战不需要子弹 |
| 日晕舞幻影 `sun_halo_dance` | `summon_sun_halo_dance`，也可沿用本体 | 当前实现为近战幻影，绑定子弹不会令其发射 |

列表从当前技能表读取，仅列 `summon_count > 0` 或 `phantom_count > 0` 的技能。黏土蜘蛛、须佐等不是独立召唤单位，不进入此列表。变身替换本体形象不属于本次入口。

## 保存、取消与战斗行为

- 独立配置保存到 `data/summon_art/<技能键>.tres`，不修改技能伤害表、射程、攻击方式或召唤寿命；重新生成数值表不会覆盖绑定。
- 同类召唤物共享绑定。当前没有逐只随机外观配置。
- 选择「未指定」并保存即可解除对应绑定：普通召唤物回退白模；幻影回退本体形象；子弹回退默认白模。不会自动猜测本体子弹。
- 缺少资源时保留缺失键提示；保存会校验四态各六帧及子弹飞行段。正式运行缺图仍有白模兜底。
- 出膛时记录召唤技能身份。施法者离场、召唤槽位被其他召唤物复用后，在途子弹保持原来的资源和出手偏移。
- 已显示的召唤物死亡或到期时，独立播放一次倒地/消散段后隐藏，不占用战斗槽位，也不阻止新的召唤。暂停时退场动画不推进。未被渲染过便消失的短暂单位不会额外补播尸体。
- 出生烟可在本页选择已生成的六帧瞬时效果资源；`shadow_clones` 白色云团、`pursuing_fangs` 贴地冷灰烟圈、`white_copy` 白色孢子烟、`puppet_crow` 沙灰傀儡烟、`vampire_bugs` 银紫旋雾与 `sun_halo_dance` 冷蓝紫显形光均已绑定。六类独立召唤入场已覆盖；吸血返回连线与变身外观另按各自状态记录，不能因为四态绑定完成就一并标为已完成。

# 忍者奔跑动作出图记录

## 共用验收标准

- 六帧、10 fps、向右循环；第 6 帧接回第 1 帧连续。
- 原著造型和项目现有战场形象保持一致，使用侧身忍者跑姿：上身前压、双臂后摆。
- 用固定服装标记追踪左右腿身份：夕日红的腿环和腿包固定属于左腿，整个循环不得因前后摆动而换腿。
- 膝关节只向自然方向弯曲；接触帧脚掌贴地，承重脚位于髋部下方；不允许交叉腿、融合腿、缺脚或多肢。
- 六帧共用身体尺度、地面基线和身体中轴。不能按整个人物透明包围盒重新居中，否则摆动的双腿会推着身体左右横移。
- 成品保持原画布与 `PBActorSkin.pixel_scale`，只替换 `run_0.png` 至 `run_5.png`。

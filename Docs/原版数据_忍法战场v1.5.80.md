## 2. 属性克制

**五系克制是用 WarCraft 3 的「攻击类型 × 护甲类型」表实现的**，而这张表被地图作者改过（不是引擎默认值），改出来的正是一个五元环。

### 2.1 系与引擎类型的对应

| 系 | 攻击类型 | 护甲类型 | 代表角色 |
|---|---|---|---|
| 火 | `spells` | `divine` | 宇智波带土 / 斑 / 止水 / 鼬 |
| 风 | `pierce` | `large` | 漩涡鸣人 / 手鞠 / 阿斯玛 |
| 雷 | `magic` | `small` | 旗木卡卡西 / 四代雷影 / 奇拉比 |
| 土 | `siege` | `medium` | 三代土影 / 油女志乃 / 奈良鹿丸 |
| 水 | `hero` | `normal` | 桃地再不斩 / 干柿鬼鲛 / 五代水影 |
| 物理 | `normal` | `none` | 洛克李 / 迈特凯 / 天天 / 君麻吕 |
| （变身） | `chaos` | `hero` | 六道形态、秽土转生、辉夜 |

对应关系不是猜的，有两条独立证据：**①** 把系代进克制表，五个位恰好首尾相接成一个环，正打 2.00、反打 0.50，一处例外都没有；**②** 卡片说明里直接写着属性 —— 例如「大蛇丸（SR）攻：风属性 防：风属性」、「日向雏田（SR）攻：雷属性 防：雷属性」、「大野木（SR）攻：土属性 防：土属性」，与①逐条吻合。

### 2.2 克制环 —— **五档，不是三档**

```
火 → 风 → 雷 → 土 → 水 → 火
```

**五系之间的倍率是「环上要走几步」的纯函数**，25 组配对逐格验证、无一例外：

| 环距 | 含义 | 倍率 |
|---|---|---|
| 0 | **同系** | **0.50** |
| 1 | 我克它 | 2.00 |
| 2 | **隔一个** | **0.75** |
| 3 | 隔两个 | 1.00 |
| 4 | 它克我 | 0.50 |

> **同系那一格是 0.50，不是 1.00。** 带一个和本波同系的忍者不是「白带」，是**主动做错** —— 和被克吃一样的惩罚。选对与选错因此差 **4 倍**，而不是只看「克制 200% / 被克 50%」时以为的 2 倍。

> **隔一个是 0.75，不是 1.00。** 五系里只有「隔两个」那两格才是真正的无关属性。

**物理是中立位**：`normal` 攻击对每种护甲都是 1.00（只有对 `hero` 护甲是 0.50），`none` 护甲挨每种攻击也都是 1.00。它既不克谁也不被谁克 —— 这是它的定义，不是配漏了。**配上同系 0.50 之后，物理队买的是「永远不会选错」** —— 实测一支固定不换人的五系队伍平均倍率是 0.95，反而输给纯物理队的 1.00。五系那 2 倍加成**全部**来自每波换人。

## 3. 三围与数值换算

**所有忍者的物编基础值完全相同**：生命 100、查克拉 100、护甲 4、伤害骰 1、攻击间隔 1.5、等级 5。物编里的单位是个**空壳**，真正的差异全在**力量 / 敏捷 / 智力**三围以及它们的每级成长上（69 个可选单位里有 65 种互不相同的三围组合）。

换算系数在 `war3mapMisc.txt`，全部是引擎默认值：

| 系数 | 值 | 含义 |
|---|---|---|
| `StrHitPointBonus` | 80.0 | 每点力量 +80 生命 |
| `StrAttackBonus` | 3.5 | 每点主属性 +3.5 攻击力 |
| `StrRegenBonus` | 0.25 | 每点力量 +0.25 生命回复 |
| `AgiDefenseBonus` | 0.22 | 每点敏捷 +0.22 护甲 |
| `AgiAttackSpeedBonus` | 0.009 | 每点敏捷 +0.9% 攻速 |
| `IntManaBonus` | 0.7 | 每点智力 +0.7 查克拉 |
| `IntRegenBonus` | 0.01 | 每点智力 +0.01 查克拉回复 |
| `DefenseArmor` | 0.02 | 每点护甲减伤 2%（走 `armor/(1+armor)` 那条曲线） |

于是一个忍者在等级 L 上的真实数值是：

```
力量(L) = 力量基础 + 力量成长 × (L − 1)      敏捷、智力同理
生命    = 100 + 力量 × 80
攻击力  = 1 + 主属性 × 3.5
护甲    = 4 + 敏捷 × 0.22
攻速    = 1 + 敏捷 × 0.009        （攻击间隔 = 1.5 / 攻速）
查克拉  = 100 + 智力 × 0.7
```

> **主属性同时决定定位**：力量 = 前排 / 肉，敏捷 = 物理输出，智力 = 忍术输出 / 辅助。卡片说明里那个「特长」栏（肉 / 前排 / 爆发 / 群体伤害 / 持续输出 / 控制 / 辅助）就是照这个写的。

## 6. 羁绊（45 组）

**每组羁绊给每个成员各发一份「属于他自己」的效果**，不是全组共享一份。例如〔传说中的三忍〕里大蛇丸召万蛇、纲手召蛞蝓、自来也召蛤蟆文太 —— 三份效果各不相同。只有少数几组（〔历代火影〕〔宇智波一族〕）才是全体成员拿同一句。

**绝大多数效果的形状是「强化这个角色的某个技能」**，而不是「全队 +X%」—— 这一点决定了羁绊必须建在角色技能之上。

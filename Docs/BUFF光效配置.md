# BUFF 光效配置

## 引擎中的操作

1. 打开编辑器底栏 **战场特效 → BUFF光效**，选择标有 [友方] / [敌方] 的对应 BUFF，再选切图目标“背后层”或“身前层”。
2. 直接选 `aires/` 的 AI 整张序列图。设置列、行、帧数和背景：透明图选保留透明，黑底金光选黑底发光；支持网格与空白带切分。原图不改写。
3. 点“切图并预览”检查编号和环身效果，或直接“一键切图并保存光效”。左右、上下按阅读顺序切；两层全部帧必须同画布，可只配置一层。已有成品 PNG 仍能直接导入。
4. 选择混合方式：亮色光晕用“加色光效”，黑影、灰雾、实体缠绕用“普通透明”。再调整帧率、缩放、脚底 X/Y 和偏移。灰色人形约 60 屏幕像素高；关闭播放后可逐帧检查。脚底坐标以切完的成品画布为准。
5. 点“保存光效”。成品写入 `assets/fx/buffs/<BUFF键>/back|front/frame_0.png`…，配置写入 `data/buff_art/<BUFF键>.tres`；两层各自保留原图和切图参数。下一次运行读取配置。清空或导入一层后同样需要保存。

混合方式保存于每份美术资源的 `blend_style`，旧资源默认加色。普通透明保留颜色与透明度，适合深色实体和影子；加色适合光带、粒子、光晕。前后层共用该资源的混合方式。同一单位不同BUFF可使用不同方式，同一前/后层内普通透明先画、加色后画。背景去除与运行时混合是两件事：黑影不要选择“黑底发光”去底，优先使用真正透明图，或洋红底软抠。交付键 `buff_hokage_line_guard` 对应列表中的 `hokage_line_guard`，资源名不重复加 `buff_`。

### 已配置示例：历代火影

`aires/skills/buff_hokage_line_guard.png`：3 列 × 2 行、6 帧、黑底发光、256×256 成品、10 fps、背后层。脚底 (128,236)，缩放 0.4。已经通过真实编辑器一键切图保存并检查截图；原图保留。它仍只提供 **+30 护甲** 的状态光，不产生护盾。

## 起手光效：整图制作与技能绑定

1. 打开 **战场特效 → 起手光效**，填写光效键（例如 `castGlowA`），点“新建 / 读取此光效”。也可从已有资源列表读取。
2. 选择 AI 整张序列图、前后层、去底方式和混合方式（同BUFF页）。操作与 BUFF 页相同：切图预览、脚底锚点、缩放、逐帧检查。六帧起手光默认 **20 fps**；人物六帧动作仍是 **10 fps**，两者独立。
3. 点“一键切图并保存光效”。成品在 `assets/fx/casts/<光效键>/back|front/frame_0.png`…，光效资源在 `data/cast_art/<光效键>.tres`。
4. 打开 **战场特效 → 技能表现**，选技能，刷新起手光列表，选 `castGlowA` 并点“绑定起手光”。同时可选择人物已有的 `skill1` / `skill2` 和命名技能子弹。
5. 起手绑定保存在 `data/skill_art/<技能键>.tres`。选择“无起手光”再绑定即可解除；不改技能数值源表。

**播放规则**：起手光只在动作的 **0–0.3 秒** 显示，释放（人物第 4 帧）时撤下；晕眩、沉默、阵亡也会撤下。单次播放，较短素材停在末帧直到释放，不循环。编辑器会循环展示“起手 → 撤光”的过程，关闭播放可看指定帧。播放跟随战斗 tick，暂停不走帧，倍速跟随模拟。

起手光不创建数值 BUFF，也不占 32 格 BUFF 槽。没有绑定时不显示。需要释放尾光时应另配释放段，当前本入口仅处理起手段。人物动作总长 **0.6 秒**，没有专属动作时使用攻击动作；攻击速度不改变施法时长。

## H 类瞬时恢复

1. 打开 **战场特效 → 瞬时恢复**，只会列出 `buffs.tsv` 中“瞬间”档效果；操作方式与 BUFF 光效页相同。
2. 透明六帧建议 8 fps，使用身前层；成品写入 `assets/fx/instant_buffs/<效果键>/front_0.png`…，配置写入 `data/instant_buff_art/<效果键>.tres`。
3. 瞬时效果不进入效果袋，也不占槽位。数值结算时由统一入口记录效果键与发生 tick，战场按 tick 播放一次，六帧结束或单位阵亡立即撤下。
4. 本入口只处理恢复、回蓝等友方瞬时反馈；伤害受击特效仍按当前约定不制作。

首轮验收借用现有金光整图作临时素材；演示资源与绑定不作为任何忍者的正式专属美术。专属素材仍需按 [素材规格_特效](素材规格_特效.md) 的 C 模板生成。

## 技能没有子弹时如何配置

在「战场特效 → 技能表现」选择技能，在子弹行选择模式，然后点击“绑定技能子弹”保存：

| 模式 | 行为 |
|---|---|
| 沿用默认 | 清除专属子弹引用，恢复已有默认表现 |
| 不显示子弹 | 隐藏飞行图，保留命中、区域及原定结算时间；已有子弹资源引用仍可供命中段使用 |
| 指定子弹 | 从右侧选择命名资源，并显示其飞行段 |

关闭飞行表现不把真实弹道改为瞬发，也不清除技能延迟。该设置写入 `data/skill_art/<技能键>.tres`，与起手光配置互相保留。

灰积烧已经选为“不显示子弹”：动作第 4 帧（0.3 秒）释放，等待技能的 0.4 秒延迟，在起手后 0.7 秒出现灰烬并结算一次伤害、2.5 秒致盲。区域由模拟时钟触发，不依赖子弹碰撞或美术播放完成。

## 生命周期与范围

- BUFF 光效页接入忍者（含己方召唤单位）与敌人的持续/周期 BUFF；瞬间恢复由独立“瞬时恢复”页配置，不混入循环状态列表。
- 前后层分别位于单位后/前，位置随脚底移动；敌人击飞时随画面一起抬升，不改变脚底排序；播放时钟取战斗 tick，暂停不继续走帧，倍速随战斗推进。
- 每种 BUFF 同时只画一套，多个施法来源不重复叠亮。不同 BUFF 可同时显示；请控制亮度和遮挡。
- 取消、被挤出、过期、阵亡、返回准备阶段时停止显示。没有素材时保留原有 BUFF 图标/染色，不凭空生成专属贴图。
- 历代火影已配置六帧 PNG；千代赠予仍使用可替换的程序占位光。导入任一 PNG 层会关闭占位光。

## 敌方状态配置示例（2026-09-24）

- 蛇阵减速：选 **[敌方] 万蛇罗之阵·减速 · serpent_slow**，导入 `buff_serpent_slow` 整图并切分、保存。亮色蛇影轮廓用加色；黑色实体蛇身选择普通透明。
- 蛇阵沉默：选 **[敌方] 万蛇罗之阵·沉默 · serpent_silence**，导入 `buff_serpent_silence`。头顶标记仍以脚底为锚，画在画布上方或通过负Y偏移抬高。
- 影子束缚 `shadow_hold`、灰积烧致盲 `asuma_ash` 等可绑定亮色状态光或普通透明的黑影/灰雾；鹿丸地面黑色连线仍使用“区域与连线”页，其透明混合适合黑影。
- 保存位置与友方相同：`data/buff_art/<BUFF键>.tres`。绑定不会产生状态或延长控制；只在实际状态存活期间显示。同名多来源共用一套光，不同状态可以叠加。
- 固定像素缩放，不自动适配每种敌人的身高/体型；灰色人形仅为参照，最终需在普通怪和大型怪上检查锚点与遮挡。怪物变色/白闪不调制光效颜色。
- 状态取消、挤出、到期、目标死亡、未出场、换波均撤光；引导失效时光效只读检查当前凭据，不把光效查询当作逻辑中断操作。

已用几何诊断素材完成编辑器切图/隔离保存及真实蛇阵状态切换截图，未生成或覆盖专属正式美术。

## 两个首批资源

| BUFF键 | 数值状态 | 应生成的素材 |
|---|---|---|
| `hokage_line_guard` | 开场 +30 护甲，本波可撤销；没有护盾 | 金色薄护体流光，前后层六帧，不能遮住人物；不要画盾牌或碎盾 |
| `reincarnation_gift` | 千代赠予三围，按施法来源独立保存和撤销 | 青绿生命光与三条细金光，前后层六帧，轻量包裹人物 |

提示词沿用 [素材规格_特效](素材规格_特效.md) 的 B 类环身模板；完整交付需求见 [美术资产清单](美术资产清单.md) 和对应 TSV。

## 数据与开发约束

- `buffs.tsv` 额外列的 `wave=1` 表示本波有效，持续秒必须为 0；`source=1` 表示同名效果按来源分别保存。这两项当前只允许己方普通持续效果，不能混用独立毒层。
- `skills.tsv` 的 `transfer_buff=<键>` 是献祭赠予的状态定义，三围量取施法者快照。定义只允许零值三围键，不能另配成长或其他效果。
- `bonds.tsv` 第 9 列为开场 BUFF，格式 `成员id:buff键,buff键;成员id:buff键`。目前只接固定护甲；其他属性不能仅改表冒充已接入。
- 修改源表后先运行 `src/tools/make_skills.gd`，再运行 `src/tools/make_bonds.gd`，不要手改生成资源。`data/buff_art` 是独立美术资源，不属于数值生成器清扫目录。
- 真正建队通过 `PBRunSim.lock_plan` 收集开场状态。`PBBondRules.active_passives` 默认含准备预览数值；建战斗单位时传 `include_opening=false`，再通过 `PBBondBuffRules.install` 安装定义，避免双算。定义随攻击者克隆，开波恢复，取消后本波不自动补回。
- 三围缓存统一由效果袋变更通知刷新；需要取消赠予时调用 `buffs.remove(id, tick, source_slot)`。省略来源会撤销该 ID 的全部来源。不要直接修改槽位绕过通知。

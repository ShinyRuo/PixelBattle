# 进度：角色技能与羁绊

**这份文档回答两个问题：做了哪些、还要做哪些。**
量于 **M12-e2 收口之后**（commit `75138df`），对着
[Docs/原版数据_忍法战场v1.5.80.md](原版数据_忍法战场v1.5.80.md)。

> **⚠ 这份是手写的快照，不是生成的 —— 它会过期。**
> 这个项目为「记录写的是当下的数据状态」付过很多次代价，所以先把话说在前面：
> 下面每一个数都标了**怎么重新量**，而「还缺什么」那一半标了
> **是对着哪一版词汇表分的诊**。
>
> **本文档最大的一条发现正是一份过期的分诊**：M12-c1 判定「缺读点」的那批技能里，
> 有一批在 c2 / c3 / e1 / e2 造出机器之后**今天就能做**，而 `data/skills.tsv`
> 的注释里还写着它们缺读点。见下面「分诊过期」那一节。

## 怎么重新量

四份表就是全部事实，`.tres` 是它们生成出来的（别读 `.tres`）：

| 问题 | 去哪 |
|---|---|
| 谁有哪几个技能 | `data/skills.tsv` 第 2 列（角色键）、第 3 列（技能名） |
| 谁有哪些被动 | `data/roster.tsv` 第 16 列 |
| 羁绊给谁发了什么 | `data/bonds.tsv` 第 5 列（载体）、7 列（成员效果）、8 列（技能补丁） |
| 效果词汇表 | `data/buffs.tsv`；键的定义在 `PBBuffRules` / `PBPassiveRules` / `PBSkillPatchRules` |
| 原版有什么 | 那份解包文档，技能条目的形状是 `**<档>-<角色>-<技能名>**　\`Axxx\`` |

**别拿技能名去和原版对**：标点不一样（`鲛肌·削灭斩` vs `削灭斩`），
而且一批原版技能在我们这里是**被动**不是技能（写轮眼、削灭斩、风切、柔拳、骨拔、
永恒万花筒、轮回眼、扭曲攻击），按名字对会报出一个假的缺口。
**按角色对，或者直接数「谁手上什么都没有」。**

所以「35/44 组」听起来盖了八成，而真正的进度是那 44%。

## 三、⚠ 分诊过期：一批「缺读点」今天已经能做了

**这是本文档最要紧的一条。** M12-c1 逐条判过哪些技能缺读点，而
**c2（致盲 / 晕眩 / 被动通道）、c3（召唤）、e1 / e2（增伤 / 防御 / 生命 / 移速）
把机器造出来全在那之后** —— 分诊没有跟着更新，
所以 `data/skills.tsv` 的注释里还记着一批**已经不成立**的降级。

逐条验过那 5 个手上什么都没有的人，**一半今天就能做**：

| 原版原文 | 今天落在哪 | 文档里现在还写着 |
|---|---|---|
| 阿斯玛·火遁.灰积烧「使他们致盲 2.5 秒」 | `enemy_hit_scale`（**c2 第三批**） | 「灰积烧的致盲缺读点」 |
| 奇拉比·七刀流「暴击率 +[10+2x等级]%，但暴击伤害只有 150%」 | `crit_chance` + **负数** `crit_damage` —— `PBPassiveRules.grant` 的注释里就写着「原版有降低自身暴击率这种代价型被动，负数是合法的」 | 未分诊 |
| 迪达拉·起爆黏土·巨鸟「每次攻击对目标及周围 275 范围造成额外伤害」 | `splash`（被动通道第一批） | 未分诊 |
| 飞段·咒术.死司凭血「将所受物理伤害的 25% 反弹给对方」 | `reflect`（c2 第四批）；「致命伤 1 秒内不死」那一半另算 | 未分诊 |
| 迪达拉·黏土蜘蛛「召唤黏土蜘蛛自爆，造 300 点小范围伤害」 | 一发 AOE —— c3 判过「一次性自爆，现有词汇表做得出」 | 「真召唤物」名单里没有它，但也没人做 |
| 奇拉比·尾兽外衣「+4-40 点防御，+25% 总攻击力」 | `defence` + `damage_bonus`（**e2 / e1**）；「生命低于 75% 才开」那一半缺 | 未分诊 |

羁绊那一侧同样有一条：**〔终成眷属〕日向雏田「【回天】覆盖范围提升 100%」
今天就能做** —— `radius_scale` 是 d2 的补丁键，而回天（`palm_rotation`）已经在表里。
那一组因此能当「半组」铺上，和现有 30 组半组同一个形状。

> **教训是一条结构性的**：**一份「缺什么」的清单和一份「有什么」的词汇表
> 是同一件事的两半，而它们分在两个文件里，改一边不会碰另一边。**
> 同这个项目反复踩的那条「断言写的是当下的数据状态」——
> 只是这次载体是文档不是断言，所以连红都不会红。
>
> **补它的办法**：把这份清单变成一张表 + 一个生成器（同名册 / 羁绊 / 技能那三套），
> 让「卡点」那一列去查 `PBPassiveRules.is_known` 等等，
> **卡点已经进了词汇表就直接报错退出**。那是另一步，还没做。

### 4.4 缺的读点，按它在原版羁绊里出现多少条排

> **⚠ 两个高频项是陷阱，别按频次去排它们。**
>
> **忍术抗性（10 条）做不了。** 它要求**敌人的伤害分类型**，而今天敌人只有一种
> 伤害 —— 加一个抗性字段之后没有任何一条伤害会去查它，那正是「配了不生效」，
> 比「配不了」难查得多。降级已经记在 `PBPassiveRules` 顶上。
>
> **⚠ 攻速那一条我先前判错了，M12-c4 已经接上。** 原话是「做了约等于没做」，
> 而那**只对一条路成立**：往 `PBAttacker.attack_speed` 上加，随后 `prime`
> 会按 `dps × 间隔 ÷ tick_rate` 反推每发伤害，加成被整个抵消。
> 换一格自己的数（`attack_speed_bonus`）**只缩间隔、不参与反推**，
> 产出就真的按加成放大 —— 实测又旅 Lv10 名义 +13%，100 秒产出 ×1.145。
> **临时那一份（效果袋）还没做**：今天原版没有一条要它，等有人要再按
> 暴击那一对的形状加，并在同一个读点相加。

# 玩法拆解：忍法战场（魔兽争霸3 RPG）

本项目要复刻的原版地图，系统骨架与设计原理的考据资料。

**用途**：理解「为什么这么设计」。具体要做成什么样看 [施工策划案.md](施工策划案.md)。

**资料来源**：玩家攻略（「夏瑶」的机制简介与新手指南）+ 一份玩家整理的系统拆解。
两份都是玩家视角的片段，不是官方设计文档。凡由结构推导得出、原文未明说的，
下文标注为「推断」；未覆盖的空缺见最后一节。

---

## 核心判断

这不是「自走棋换皮火影」。深度来自一个别处很少见的组合：

1. **敌人属性按固定顺序轮转**
2. **200% / 50% 的极陡克制**
3. **板凳席等于生产力**
4. **手动聚怪把 AOE 的实际收益放大数倍**

四个拿掉任何一个，它就塌回一个普通的挂机刷怪游戏。

---

## 一、属性克制（地基）

五系单向环，来自火影原作的查克拉性质相克，没有魔改：

```
火 → 风 → 雷 → 土 → 水 → 火
（箭头 = 克制方向，A → B 表示 A 打 B 造成 200%）
```

每系恰好克一系、被一系克，没有孤立系也没有双克 —— 这是它能被用作「波次锁」的前提。

### 伤害系数

| 关系 | 系数 | 相对基准 | 设计意图 |
|---|---|---|---|
| 克制 | 200% | ×1.90 | 带对属性的巨额奖励 |
| 被克 | 50% | ×0.48 | 带错属性的巨额惩罚 |
| 无关 | 100% | ×0.95 | **推断值**，攻略未明说 |
| 普（物理） | 105% | 基准 | 无视属性的保底选项 |

### 105% 是全局最重要的旋钮

物理不吃克制、恒定 105%，比「无关属性」略高一点点，但远低于克制的 200%。
它是一条**永远可用、永远不最优**的保底线：

- 缺某一系时，物理是补丁 —— 不会崩，但也别指望效率
- 物理英雄（迈特凯、飞段、天天）成了阵容里的**方差保险**
- 只要往上调一点点，堆物理躺赢就会变成最优解，整个属性系统随之作废

### 波次轮转把克制变成了排班表

攻略里那句轻描淡写的「出兵属性顺序为：火，雷，水，土，风」，是整张图最关键的一行信息。
因为出怪顺序**固定且公开**，玩家可以提前排班：

| 波次序 | 敌方属性 | 你需要的输出 | 绝对不能靠 |
|---|---|---|---|
| 1 | 火 | 水（水克火） | 风 |
| 2 | 雷 | 风（风克雷） | 土 |
| 3 | 水 | 土（土克水） | 火 |
| 4 | 土 | 雷（雷克土） | 水 |
| 5 | 风 | 火（火克风） | 雷 |

**五波用满五系。没有任何单系或双系阵容能跑完一轮。**

这一条从机制上堵死了自走棋最常见的病 —— 一套最优解 comp 统治版本。
而且 200%/50% 是 4 倍摆动，意味着「带对属性的二线英雄」几乎永远优于
「带错属性的一线英雄」，玩家注意力被强制拉到*配比*而不是*抽强卡*上。

### 实现要点：属性挂在伤害实例上

攻略提到**迪达拉的 Q 是土属性，但他被列进火系输出梯队** —— 同一个英雄的不同技能
可以是不同属性，攻略也明说「英雄技能说明与攻击图标即可看到详细比例」。

所以 `element` 必须是**伤害事件**的字段，不是单位的标签。单位身上的属性只是 UI 归类
和羁绊判定用的默认值。一开始写对，后面才能扩展多属性英雄、属性转换 buff、附魔改属性。

## 二、经济：三条流，三种风险曲线

| 来源 | 触发 | 数值 | 占场上位 | 风险特性 |
|---|---|---|---|---|
| 经济升级 | 每 0.5 秒 | 递增 | 否 | 无风险，一次性投资 |
| 角都 | 每回合结算 | 等级 × 85 | 是 | 与战斗脱钩，稳定，多个减半 |
| 纲手 | 每次击杀 | EV +13 | 是 | 与清怪量强绑定，打不动就断粮 |
| 任务 | 每回合结算 | 未知 | 占备战席 | 要求 2 名不上场忍者，忘放则为 0 |

### 纲手的期望值

攻略给的三段分布：50% 得 35、30% 扣 15、20% 不动。

```
EV = 0.50 × (+35) + 0.30 × (−15) + 0.20 × 0
   = 17.5 − 4.5
   = +13 / 击杀
```

确实「总体是纯利润」，但请注意这个设计的用心：**它给了一个稳赚的收益，却把它包装成
一个会看到扣钱的老虎机。** 玩家会记住那 30% 的负反馈，主观上觉得纲手「不稳」，实际
长期必赚。用体感波动换取注意力投入，同时不真的伤害经济 —— 很老练。**别去「修」它。**

### 两种经济的方向相反

- **纲手 = 正反馈**：杀得快 → 钱多 → 更强 → 杀得更快。滚雪球型，前期弱势时一起崩，属于**赢家加成**
- **角都 = 负反馈缓冲**：按回合按等级发钱，跟打得好不好无关。打崩了照发，属于**输家保险**

一个赌注、一个底薪，玩家在两者之间的配比就是风险偏好的表达。这是经济设计里最漂亮的一处。

### 但角都是明显的平衡漏洞

攻略同时把角都列进了**雷系 AOE 输出第 2 名**。别的经济位要付「占一个战力空位」的代价，
角都不用 —— 一个位置同时交付经济和输出。

这直接解释了攻略里那句「熟悉后可以玩转 2～3 个角都」：即使有「多个减半」的递减，
叠角都依然划算，因为你付的从来不是真的空位。这也是原版流派单一的直接原因。

### 核心张力：经济位 = 战力空位

攻略原话：「建议出 1 个角都和 1 个纲手即可，因**前期打不死怪损失比额外加的多得多**。」

这句话是整局节奏的支点。经济投入有一个**硬下限** —— 低于某个清怪速度，所有经济收益
归零（怪打不死 → 纲手不产出 → 漏怪掉血 → 出局）。所以经济曲线不是自由的，它被一条
「当前波次生存线」压着，而这条线随波次上升。

## 三、双站台：原版最聪明的设计

- **出战席**：参战、产生伤害、占出战人口、羁绊生效
- **待命台**：不参战、不占人口、**羁绊全额生效**、可做任务

这把**羁绊和战力彻底解耦**了。出战人口不再用来凑羁绊，只用来放输出；待命台变成
羁绊仓库。高阶玩法就是「用最少的上场位撑起最多的羁绊」。

比 TFT 的「上场即羁绊」更有嚼头。

### 但原版的取舍没做出来

如果待命台格子够多且羁绊全额生效，最优解永远是「能凑羁绊的卡全塞进去」，不存在决策。
原版靠格子数量做隐性限制，但攻略里没有任何取舍的讨论 —— 说明这个系统的张力是空的。

> 本项目的解法：把任务派遣做成待命台的「占用成本」。见施工策划案 §06。

## 四、任务：板凳即产能

攻略新手第一条，也是最容易漏的一条：

> 每回合需记得做任务（放两个不用上场的忍者在备战区，若不放任务不加钱）。

这一句把在别的自走棋里纯属浪费的东西 —— **板凳深度** —— 变成了收益来源：

- **回收沉没成本**：重复卡、当前波次属性不对的卡不再是废牌，Bad Roll 的挫败感显著降低
- **构成软性上场人数上限**：没有硬规则，但每多上一个人就少一份任务收入。
  上场数量成了**连续的经济决策**而不是天花板 —— 比硬上限优雅得多
- **给了备战席存在理由**：玩家有动机维持有深度的替补池

### 但「忘了就白给」暴露了 UX 失败

一个**每回合都要做、忘了就白给**的操作，需要写进新手指南第一条 —— 说明游戏内既没有
提示也没有默认行为。这是纯操作税，不产生任何决策乐趣：没有人会「战略性地选择不做任务」。

## 五、吸怪：隐藏乘数

攻略新手第 5 条：「学会使用吸怪：将怪聚集在一起，使 AOE 输出到最多人。」

这条揭示了关键事实：**这张图不是纯自动战斗。**

```
实际清怪速度 = AOE伤害 × 聚怪数量 × 属性系数
```

三个因子里，前后两个由构筑决定，中间那个由**手上功夫**决定。同一套阵容，会聚怪和不会
聚怪的通关波次可能差出一倍。

它还反向解释了羁绊的设计：凯班和第七班之所以被推荐，核心不是数值，是它们各自打包了
一个聚怪工具（木叶旋风 / 神威）。**羁绊在卖的是「操作层的能力」。**

| 羁绊组 | 成员 | 分工 |
|---|---|---|
| 凯班 | 李洛克、天天、日向宁次 | 小李聚怪，宁次「放家里」（后排） |
| 第七班 | 卡卡西、宇智波带土、野原琳 | 神威把整波怪吸成一点，琳给团队增益 |

两组的共同结构是 **聚怪 + 输出 + 支援**。羁绊的真实作用是**把一套完整的操作 combo
打包成一个可抽取的目标**，而不是给一个 +15% 攻击。这比数值型羁绊高一档 —— 凑齐后
**玩法本身改变了**，而不只是数字变大。

> **这是复刻时最容易丢掉的东西。** 做成纯自动战斗，聚怪消失，AOE 收益拍平成常数，
> 技巧上限归零，游戏退化成拼数值抽卡。本项目的替代方案见施工策划案 §02。

## 六、装备：三级树 + 一个新手陷阱

每个英雄 3 件装备，配件放身上**自动合成**（TFT 式）。

| 成品 | 配方 | 特效 | 定位 |
|---|---|---|---|
| 双刀 | 2×针千本 + 忍者头盔 | 普攻伤害 +20% | 物理 |
| 钝刀 | 针千本 + 2×忍者苦无 | 10 点护甲穿透，攻击力 +100 | 物理 |
| 吸血刀 | 针千本 + 忍者足具 + 武者护手 | 造成伤害 15% 吸血 | 物理 |
| 雷牙 | 2×封印全套 + 忍者苦无 | 法术伤害 +20% | 法术 |
| 暗部面具 | 封印全套 + 2×忍者头盔 | 法伤 +12%，全属性 +30 | 法术 |
| 火影风衣 | 3×忍者披风 | 50% 概率格挡 260 伤害 | 坦克 |
| 真武 | 3×同类 SR + 制作书 / 4×随机 SR + 制作书 | 未知 | 终局 |

结构很干净：**配件 → 成品（3 配件）→ 真武**。配件只有 7 种，复用率高，认知负担可控。

数量前缀（「2×雷牙」「3×火影风衣」）说明**同款成品可叠加、无唯一限制**，3 件槽位
鼓励堆同款走极端。这是明确的构筑倾向：**专精 > 全面**。

### 5000 箱是新手陷阱

攻略原话：「个人不建议购买 5000 的箱子随机装备，全狗密 1350 的箱子」。

- **1350 配件箱**：出配件，可分类囤积、按需定向合成 → 玩家有**控制权**
- **5000 成品箱**：直接出随机成品 → 省事，但可能完全用不上

老玩家一致选择前者，意味着 5000 箱**期望价值配平失败** —— 贵 3.7 倍却因为不可定向而
实际更差。它现在唯一的作用是惩罚不看攻略的新手。

## 七、尾兽

开局从 9 只中选 1，全程提供固定光环 + 一个手动大招（CD 可控）。

各尾兽机制差异化：四尾灼烧输出、六尾团队回蓝、七尾减敌方抗性、八尾增攻、
九尾专属强化鸣人。是 BOSS 关卡与高压波次的核心救场手段。

> 对本项目意义重大：**这是一个低操作精度、高时机判断的干预手段**，正好可以接管
> 「吸怪」留下的技巧位。见施工策划案 §11。

## 八、系统耦合

主循环：

```
金币池 ──抽忍者/买装备──> 战力
  ↑                          │
回合结算              属性匹配 × 吸怪
  │                          ↓
收入 <──击杀金·波次结算── 清怪效率
```

所有系统都是对这个环的某一段收税或加杠杆：

| 系统 | 作用于 | 作用方式 |
|---|---|---|
| 属性克制 | 战力 → 清怪 | **闸门**。带错属性时把转化率砍到 1/4 |
| 吸怪操作 | 战力 → 清怪 | **乘数**。构筑之外的变量，由手上功夫决定 |
| 装备 | 金币 → 战力 | **杠杆**。第二条转化路径，可长期复利 |
| 纲手 | 清怪 → 收入 | **放大**。正反馈 |
| 角都 | 直接注入金币 | **旁路**。绕过整个环，代价是一个战力位 |
| 任务 | 备战席 → 收入 | **回收**。把环外闲置资产接回环内 |
| 经济升级 | 直接注入金币 | **底噪**。无风险纯时间流 |

整体形状是：**两条旁路绕过战斗给钱，一条回收路捡起闲置资产，一个闸门和一个乘数卡住主干。**

玩家的每一个金币都是在「投进主干」和「投进旁路」之间选边。而主干的回报率受属性配比和
操作水平调制，旁路的回报率恒定但要付位置税。

**这就是它耐玩的原因：没有一个全局最优比例。** 主干的回报率随阵容质量和手法水平浮动，
每个玩家的最优解都不一样。

## 九、原版的设计债

以下不是设计，是魔兽编辑器的限制或未完成的配平。**复刻时直接删掉或修掉。**

| 问题 | 成因 | 处理 |
|---|---|---|
| 「将蓝装分类放置在不同地方」 | 6 格物品栏 + 无条件自动合成导致误合 | 独立仓库 UI + 手动确认合成 |
| 「若不放任务不加钱」 | 无提示、无默认行为 | 见施工策划案 §06 的改造 |
| 属性比例要点开技能说明才看得到 | UI 缺失 | 常驻预告 + 覆盖度结算 + 飘字区分 |
| 5000 箱、角都双修、风系梯队薄 | 配平未完成 | 逐项修，见施工策划案 |

判断依据很简单：**老玩家已经形成一致共识去规避或滥用** —— 这是配平失败最可靠的信号。

## 十、情报缺口

攻略是玩家写给玩家的入门文，跳过了大量对复刻至关重要的信息。按重要性排：

| 缺口 | 为什么要紧 |
|---|---|
| **抽卡机制本身**（费用、概率、池子是否共享、能否刷新） | 整个经济的支出端 |
| **上场人数上限**与提升方式 | 决定阵容宽度和「经济位成本」的真实大小 |
| **待命台格子数**与解锁曲线 | 双站台取舍的关键旋钮 |
| **无尽模式缩放公式** | 难度曲线骨架，没它无法配平任何数值 |
| **任务是否有类型/条件差异** | 决定它是占位系统还是可深挖的核心 |
| **真武的实际效果** | 终局目标的吸引力 |
| **回合结构与时长** | 决定操作层节奏与实时聚怪的可行窗口 |
| **失败条件**（基地血量？漏怪扣血？） | 影响风险决策的全部权重 |
| **召唤师单位** | 攻略提到「配件放在英雄或召唤师身上」，能力完全未知 |

前四条不补齐就无法开始做数值原型。最快的补法是开图打两局录屏。

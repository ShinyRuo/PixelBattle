# Debug 测试工具

## 跳过抽卡，直接测试忍者技能

1. 运行游戏，在准备阶段点击顶栏右侧 **Debug**。
2. 在下拉框选择忍者，点击 **直接出战**。
3. 忍者以 1 级加入当前阵容并自动选中；可以继续选择其他忍者添加。
4. 点击“关闭 Esc”或按 Esc，返回战场；需要时拖动调整站位。
5. 按回车开打，点击该忍者，再从技能栏施放技能观察表现。

不扣金币、不消耗抽卡次数或随机流。每次点击创建一张独立卡，可以同时测试同名忍者。出战位置满时会提示先把现有人物移回仓库，不替换原阵容。

## 窗口行为

- 打开窗口期间，战斗和阶段推进停止；关闭后保持原先的暂停/运行状态。
- “直接出战”只在准备阶段可用。战斗中可打开窗口查看，但不能添加忍者；需等回到准备阶段。
- 添加成功后关闭自动推进，便于检查站位和选择技能。
- 抽卡选择、尾兽选择和系统菜单应先完成或关闭，再打开 Debug。
- 生成的是本局正常单位，关窗不会删除；后续波次照常保留，重开本局会清空。

## 开发扩展

`src/view/debug_panel.gd` 负责窗口和操作信号；`PBBattleView` 负责阶段检查与刷新；`src/core/rules/debug_rules.gd` 负责调试建卡和编队。新测试按钮可继续加入此窗口。出战仍走正常开波初始化，不能直接向运行中攻击者数组添加未初始化对象。

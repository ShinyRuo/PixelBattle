- **逐 tick 模型是唯一的真游戏**，挑模型只能走 `PBRunSim.resolve_battle`。
- **一发就是攻击力**（`PBAttacker.attack`），出手间隔由攻速决定，`dps` 只是统计量。攻速上限封在**间隔**上不是攻速上。
- **两个唯一落点**：`PBStrikeRules.land`（我方打敌人，近战 / 范围 / 子弹都调）和 `PBStrikeRules.hurt_ally`（敌人打我方）。忍者**掉血**再收一层到 `PBStrikeRules.wound_ally`（敌人攻击与自身掉血 `drain_max` 都走它），阵亡记账、血量阈值触发（`low_hp`）、致命伤抵挡（`on_lethal`）挂效果、阵亡技能记账都在那里，一波一次；阵亡技能由 `PBBattleSim._fire_death_casts` 以尸体为落点走 `_land_skill` 放出去。闪避、重生、减伤、护盾判在 `PBAttacker.take_damage` 里面；易伤判在 `PBEnemy.take_damage` 里面；晕眩判在 `PBEnemy.ready_to_fire` 里面。扫描式断言钉着调用方不许自己判。
- **掷骰只有该掷时才掷**：暴击率 / 闪避 / 致盲为 0 时一次都不掷，否则退化路径的对拍会错位。战斗内部的随机流是本波派生流（`PBRngStreams.battle_rng`），不是 `combat` 流。
- **敌人闪避只认普攻**：近战、范围、子弹、溅射与穿透都将战斗随机流传入 `PBEnemy.take_damage`；技能、持续伤害、反弹不掷闪避。闪掉主命中后不吸血、不溅射、不挂命中效果，也不记虚假的伤害播报。敌人暴击在 `PBCritRules.enemy_strike` 出手时只掷一次，子弹保存伤害与标记；飞行期间 BUFF 消失不改这一发。临时概率 / 暴伤复用 `DODGE`、`CRIT_CHANCE`、`CRIT_DAMAGE`；出生时清除旧概率和闪避计数。
- **敌人护盾与受伤倍率**：`PBEnemy.take_damage` 内按「闪避 → 易伤 × 受伤倍率 → 护盾 → 血量」处理；护甲 / 忍术抗性由各伤害类型入口先折算。护盾消耗只走敌我共用的 `PBBuffBag.absorb`；`damage_to_kill` 用同一倍率和有效护盾换算连续输出的击杀消耗，无敌时为 `INF`。吸血仍只认实际掉血，护盾余量不计入。
- **定长数组是隐含前提**：召唤物位子开波预留，跑动中不往数组里塞人。
- **停在射程的九成上**（`PBAttacker.STOP_RING`，敌我共用），正好踩边界时浮点会让人判定够不着。

### 属性、名册、词条

- 克制矩阵是**环距的纯函数**，仙是第七个属性、不进 `PBElement.PICKABLE`。**新属性只能追加在枚举末尾**（值直接存进 `.tres` 与存档）。
- 名册、羁绊、技能全部**由表生成**（`data/*.tsv` + `src/tools/make_*.gd`），名字只在 `data/`（铁律 5）。**生成器遇到不认识的键直接报错退出。**
- 名册那条路**不调 `fill_placeholder`**（会把真三围抹平回稀有度阶梯）。
- **词条分两层**：属性词条（`PBStatRules`，算三围那一刻注入、克制之前）和行为词条（`PBPassiveRules`，建人之后装）。「认不认得」只问 `PBModRules.is_known`。
- 局面给的词条（装备 + 训练科技）都并在 `PBCombatRules.unit_mods`，它已经接到全部折叠点（战斗、估值两处、任务卡预览）；和 `unit_multipliers` 两条腿都要走，扫描式断言钉着。

### 技能、效果、羁绊、尾兽

- 效果层三类：`PBBuff`（定义）/ `PBBuffState`（一份正在生效的）/ `PBBuffBag`（一个单位身上的全部）。**持续效果永远不写回基础字段；过期是查询时比 tick。**
- **词汇表里的键 = 已经接上读点的键**，不预留。`test_passive` 那条「每个键都要真的改动点什么」抓过好几次漏接的读点。
- 技能按每人一份 `clone()` 现造，**补丁打在复制品上**，`on_hit` / `on_self` 数组必须复制（里面的 `PBBuff` 共享）。
- 羁绊按**角色数**不按卡数；**多组给同一个人同一个键时量相加**；落在大招上的功能键不许两组共用；功能档一组只出一个载体。
- 尾兽光环写「每级多少」，发的时候乘等级；尾兽大招跨波保留冷却。
- **技能落在我方按半径圈人只有一处**（`PBSkillRules.land_around_allies`）：「不用点」的圆心是施法者，「点地面」和阵亡技能的圆心是落点 / 尸体。漏掉的表现是按了扣蓝进冷却、谁身上都没效果（真出过）。
- 阵亡技能不进指令卡：技能表角色键写 `-`，由羁绊补丁 `on_death` 发给成员。

### 界面

- **一个忍者只在一处**：战场 / 仓库 / 任务栏，拖放和指令卡按钮走同一批 `PBCardMoves` 函数。
- **任务栏里站着几个人就是接不接任务**，没有按钮；人数不符是失败，那几个人照样离场。
- 战场上的 `Control` 一律 `MOUSE_FILTER_IGNORE`（默认 STOP 会吃掉战场点击）。
- 鼠标坐标一律走 `make_input_local()` / `get_global_mouse_position()`（`stretch/mode` 是 `canvas_items`）。
- 画地面上的圆只准走 `PBLayout.ground_disc`（屏幕上是椭圆）。
- **词条写成字只走 `PBShopLabels.mod_words`**（装备、羁绊、尾兽光环三处共用）：成数乘 100、非整数写一位小数都在那一处。
- 渲染层要的「事件」（挨打、暴击、施法回音、命中火花）读**战斗播报**或逐帧比状态，不往 sim 里加事件流。播报游标比 `PBBattleLog.total`，不比 `entries.size()`。
- 暂停下的施法指令先攒着（`PBSkillOrders`），取消暂停一起放；点名不排队。
- **说明卡上的效果描述一律从数据现生成**（`PBEffectWords`），不手写描述文字；技能格、buff 格、羁绊行都只悬停不点开。效果键加一个就要在语言表补一条句式，漏了测试红（否则卡上漏出 `buff_fx.xxx`）。
- 语言表是 `make_locale.gd` 从 tsv 派生的，**显示名不一定在第 2 列**（技能表在第 3 列）；取错列的表现是技能格写着角色的英文键。
- 底栏忍者信息卡只有 94 高：不放克制倍率、站位、装备；攻防属性写在攻、防后面；羁绊占最后三行，每组只写「名字 人数」、只悬停不点开（玩家定的）。多一行的表现是最底下的羁绊被挤出框，不报错。**羁绊折行由 `PBUnitInfo._pack` 自己量宽度做**，交给 RichTextLabel 的话中文会把一组名字劈成两行。

### 美术与素材流水线

- **白模兜底必须一直活着**：素材大部分不进版本控制，干净机器上跑出来几乎全是白模，而它不报错。
- 流水线只有一份（`PBActorForge` / `PBPixelate` / `PBPortraitForge` / `PBFxForge`），命令行和插件都是调用方。
- **编辑器插件调用的每个脚本类都得是 `@tool`**：不带它的脚本在编辑器里 `.new()` 出来只是占位，调方法什么都不发生、也不报错。只读写导出字段的资源不用。
- **子弹精灵和 sim 的子弹槽一一对应**（`PBShotPool`），不按「活着的第几发」挤着排：每发子弹从飞行段第 1 帧播起靠的就是它。命中段可以不配，没配就用默认火花（判据在 `PBShotPool._spark` 一处）。洋红底抠图是软抠 + 去色溢（`PBFxForge.soft_key`），二值抠会留一圈紫边。
- **原版码数只有一处换算**：`PBSimConfig.war3_units_per_field`（2000 码 = 1 个战场长度）。忍者射程存原版码数（`PBCharacter.attack_range`），战斗和射程圈都走 `reach_of`；「攻击距离」列（近战/远程）只决定站哪一列。被动 `splash_radius` 同样存码数，换算在 `PBStrikeRules.splash_reach`。技能表的「范围」是早先按同一比例手算好的战场坐标，改比例时要一起重算。
- **特效配置逐个配，不按属性推**：普攻子弹在名册「普攻子弹」列（`PBCharacter.shot_key`），敌人的按皮键配在 `data/enemy_shots.tsv`（`PBEnemyShotTable`，渲染层读、面板写，不经过生成器），技能子弹 / 命中 / 落地 / 光环各自配在技能表、效果表里（后几项未接）。发光类黑底出图、加法混合，实体类洋红底、普通混合，两段各自一个开关。
- **战斗画面按键一份一份读形象**（`PBActorLibrary.skin_for` 只读 `data/actors/<键>.tres`），文件名必须等于键。一次读全目录（88 套、60 多兆）会让开局第一次点选忍者卡几秒到十几秒。
- 脚底是唯一的锚点；朝向判据只有 `PBActorSkin.flips_for`；非循环段「停在最后一帧」只有倒地那一档。
- `SPRITE_HEADROOM`（排版）和 `CANVAS_CEILING`（素材）是两个数；人物 60 像素高是这块屏幕的天花板，再高要动配平。

### 测试

- **断言写规则，不写当下的数据状态**。这个项目反复踩的坑：「恰好 N 组」「每个角色都有头像」「应有三种配件下架」这类断言在内容变多或 bug 修好时变红，而红的不是错误。改成「表和目录对得上」「每张头像都要有主」「有效果却估值为 0 不许出现」。
- **扫描式断言**钉「只许一处判」的漏斗：光测效果对不对拦不住漏掉的那条路径，因为测试根本没走到它。
- 测试直接调 `build_attackers` 抓不到接线漏洞，关键接线要有一条走完整 `PBRunSim` 的断言。
- 探针技能表先 `clone()` 配置再换空表 —— `PBGameData.config()` 返回共享的那一份。
